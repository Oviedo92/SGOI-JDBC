# SGOI-JDBC

Modulo de gestion de clientes del Sistema de Gestion de Ordenes de Servicio e Inventario (SGOI).

## Tecnologias

- Java 17 o superior
- Maven
- JDBC
- PostgreSQL
- Git y GitHub

## Modulo

Gestion de clientes: registro, consulta, actualizacion y eliminacion.

## Base de datos

La estructura de la tabla se encuentra en `database/schema.sql`.

## Ejecucion

La configuracion de la conexion y la ejecucion se documentaran cuando se implemente el modulo.
